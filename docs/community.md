# TIDE · PetLab：让时间、经历和行动参与 AI 角色的下一次反应

TIDE · PetLab 已开放技术 Alpha。Windows 上可以同时运行大肥鱼和小肥鱼：和它们聊天、拖拽互动，看它们选择动作、走近对方、递出或接受一碗饭。每只角色分别保留自己的身份、关系和经历，公开交谈与私聊按可见范围传递。

桌面背后是 TIDE 的持续交互运行内核。一次互动先经过语义量测，再由领域包计算状态、时间演化与历史影响，通过正式接受后用于后续调度。内容检索、记忆影响、开口资格和表达装配各有职责，模型选中的动作也要经过实际执行回执，才会成为已经发生的经历。

这个项目分为三层：TIDE 提供通用 Runtime；CX67（六七包）以七个角色常量和六维连续状态计算互动动力学；PetLab 负责桌面输入、表现和外部执行。开发者可以只使用 Runtime，接自己的状态模型、前端或播放器。仓库附五篇开发指南、三个离线示例和公开用例。

想直接体验，下载带本地检索模型的完整包，安装64位 Python 3.11，双击 START.cmd，再填一份兼容的聊天 API 配置即可。当前是源码技术 Alpha，自定义角色创建尚未开放，回复质量、召回与速度仍有已知限制。
