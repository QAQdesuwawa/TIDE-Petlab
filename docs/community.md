# TIDE：持续交互 Agent 的时序运行内核

TIDE 处理持续交互 Agent 在多次模型调用之间的时间、状态、历史影响和事实提交。领域模型计算变化，Runtime 正式接受，宿主执行并返回实际结果。找到旧记录、唤起历史、影响状态和交付表达分别核对，角色可以延续自己的经历，同时保留每次变化的来源与版本。

通用内核不固定人格、状态维度或某个模型服务。开发者通过模型包定义状态、演化与记忆规则，通过时间包定义坐标和进度，再接自己的前端、工具或播放器。仓库附独立 Runtime、模型调用和播放器三个离线示例，以及对应的开发指南。

CX67（六七包）是其中一个领域模型：以七个角色常量和六维连续状态计算互动动力学。PetLab 是运行在这套定义上的 Windows 双桌宠示例，用大肥鱼、小肥鱼展示独立记忆、公开与私聊、拖拽互动和有限连续动作。

想直接体验，下载带本地检索模型的完整包，安装64位 Python 3.11，双击 START.cmd，再填一份兼容的聊天 API 配置即可。当前是源码技术 Alpha，自定义角色创建尚未开放，回复质量、召回与速度仍有已知限制。
