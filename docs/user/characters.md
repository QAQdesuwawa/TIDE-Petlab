# 创建自己的角色

首版支持填写自己的名称和完整人设，量测后创建一个独立桌宠。外观、表情和动作暂时复用现有鲸鱼动画；修改人设不会自动生成新立绘。原来的大肥鱼、小肥鱼及其记忆会保留。

## 进入创建页

1. 在解压目录运行 `SETUP.cmd`。尚未安装时，先按首页说明准备 Python 和运行环境。
2. 在设置窗口点击 **创建自己的角色…**。这会打开新的角色草稿；取消不会覆盖已有配置或记忆。
3. 填写名称与完整角色背景。例如名称“小书”，背景写明身份、性格、自称、日常语气和认真回答时的风格。这里的文字会作为角色表达的人设保留，不必自己写数值。
4. 在 **模型** 页填写自己的 API 地址、模型和密钥，也可沿用刚才设置窗口中的提供方。没有密钥时不能进行背景量测。密钥可以只用于本次运行；需要下次直接恢复时勾选本机安全保存。

## 生成并启动

1. 回到 **新角色** 页，点击 **按背景生成**。它会使用配置的 API 量测人设，调用原常量生成公式；这一步会产生一次模型请求和费用，不是离线操作。
2. 等待生成成功。失败时保留草稿和错误，不会用默认数值假装生成成功。名称、人设或参数发生变更后，需要重新生成，避免旧结果配上新描述。
3. 在 **保存位置** 页可以看到新角色的配置、记忆和运行记录路径。默认位于原配置目录下的 `characters/随机标识/`，各角色互不覆盖；素材仍指向已有鲸鱼素材目录。
4. 点击 **保存并启动**。新建角色先以单桌宠运行，不会自动变成默认两只鲸鱼，也不会接管它们的记忆。仅保存配置不会产生聊天记录。

## 聊天与互动

右键角色打开对话入口，输入一句问候或角色相关问题。角色回复时显示气泡；等待期间也应可以继续拖动。左键短点与按住拖动是两种交互，拖动过程中可能按原观察与资格机制回应；不保证每一次碰触都会主动说话。

建议先验证：让它介绍名字，告诉它一个简短事实，再触碰或短距离拖动一次。用户完整人设、事件量测、正式记忆与动画各走现有通路；创建量测不等于给角色编造一段过去。

## 退出与恢复

使用角色右键菜单里的退出功能，等待程序正常退出。下次运行 `START.cmd` 会读取最近保存的启动位置，恢复这个角色及原记忆，不重新做背景量测。

如果只在上次运行临时填写密钥，下次会需要再次提供密钥。运行 `SETUP.cmd`，在模型页填写后保存并启动即可；恢复旧角色时不要点击创建新角色，也不要重新生成其常量。

保存其他角色的配置文件路径。想切回另一只单角色时，在设置中加载它的原配置，并在保存位置选择对应的原记忆。当前设置页没有单宠/双宠切换控件；切回原来的默认双宠需要从解压目录显式运行下面的命令，并换成它们原来的配置和存档目录：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 -m petlab_app --dual --setup --config "原双宠配置.json" --workspace "原双宠存档目录"
```

不要用不同角色的配置和记忆混配。若显示定义不一致，先检查路径，保留原文件。

## 当前范围

- 本功能创建的是一个独立角色，暂不提供把任意数量自创角色加入同一双宠场景的界面。
- 没有聊天记录导入按钮；批量旧聊天量测、记忆重建和联合拟合是后续目标。
- 背景量测成功只表示合同与参数生成完成，实际人设表现还需聊天体验。API错误、解析失败与角色回复质量是不同问题。
- 私人配置、创建回执和聊天记忆保存在本机，不应提交到公开仓库。
