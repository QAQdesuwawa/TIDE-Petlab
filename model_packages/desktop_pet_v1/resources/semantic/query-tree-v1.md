文字输入的记忆查询采用 memory_query_nodes 数组，每个节点绑定当前原文的一条线索，最多16个父项与来源子项合计。
父项字段为 kind、text、evidence_text；text是当前原文中能独立定位的短语（最多48字符），evidence_text是唯一定位的原文片段（最多256字符）。
kind有三类：
- literal：本句直接给出的对象或属性值，references为空。
- query：本句正在询问、需要从前文补出的对象、属性值或约定；当前出现的属性名称是问题的入口，来源中的具体值是它的子项。
- unresolved：当前线索可以定位，含义尚不足以细分，保留父项，references为空。
query的references为来源子项数组；每项为 {"reference_id":"来源标识","text":"来源里的原词","reference_text":"所选来源中包含该词的唯一原文片段"}。子项继承本query的当前证据，来源仍绑定对应reference_id。每段来源证据最多256字符，原词最多48字符。
同一查询父项承载问法，来源子项承载可补出的值；来源不足时保留query父项并给references:[]。父项与子项共同表达一次指代关系。
当前事件用于本次数字量测；此前用户话语只提供指代来源，正式记忆召回与状态影响继续由后续原机制决定。
